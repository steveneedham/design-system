How to use this header component

Integration: Copy the HTML and CSS from the <header> element above and drop it into your page. Update the content to match your page context.

Customization

Logo/Mark: Replace the placeholder SVG in .header-mark with the consulting lockup SVG:

<img src="https://raw.githubusercontent.com/steveneedham/design-system/main/consulting/urban-strategist-lockups.svg" alt="Urban Strategist">

Heading: Update .header-title text. Wrap key words in <span class="accent"> for amber emphasis.

Tagline: Edit the paragraph in .header-tagline.

Buttons: Update .header-ctas links. Use class="primary" for amber CTAs and class="secondary" for teal.

Background: The map pattern is procedurally generated as an SVG data URI. To use a real map image, replace the background-image URL in .header-background with your map PNG/JPG path.

Design system tokens used

  • --ink: Background (#14171C)
  • --amber: Primary accent (#E8A33D) — operations/emphasis
  • --teal: Secondary accent (#4FD1C5) — systems/alternatives
  • --text: Primary text (#EDEAE2)
  • --muted: Secondary text (#8B93A1)
  • --panel-line: Borders (#282E38)

Responsive: Component uses clamp() for fluid typography and breakpoints at 640px for mobile optimization.
