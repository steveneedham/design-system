Urban Strategist Header Component

Reusable header component with Scioto River map background, built on the design system.

Live Demo

Usage

To use this component in your own pages:

Option 1: Copy the component

Copy the HTML and CSS from components/urban-strategist-header.html and customize as needed.

Option 2: Embed via iframe

<iframe src="https://steveneedham.github.io/design-system/components/urban-strategist-header.html" width="100%" height="600" frameborder="0"></iframe>

Customization

  • Logo: Replace the placeholder SVG with your mark
  • Heading: Update the h1 text and use .accent spans for amber emphasis
  • Tagline: Edit the paragraph text
  • Buttons: Update href and text for CTAs
  • Map: Change the background-image URL to use your own map

Design System Integration

The component uses the design system's core tokens:

  • Colors: --ink, --amber, --teal, --text, --muted
  • Typography: Fraunces (display), Inter (body), JetBrains Mono (mono)
  • Responsive breakpoint at 640px for mobile
